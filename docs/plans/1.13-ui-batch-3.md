# Plan: UI batch 3 → release 1.13.0 (both apps, one release)

The owner's picks from the senior UI/UX review (18 Nov 2026): **61 items**, built in the classic React app (`src/`)
and the Flutter app (`rxpos_flutter/`), tested, screenshotted for the owner, then **released together once as 1.13.0**.

This file is the hand-over. Any session can pick up from it: read "How to pick up", find the first unticked item, build
it in both apps, tick it here in the same commit, push.

## How to pick up

- **Branch:** `claude/festive-dijkstra-1pgrof` (pushed; 1.12.0 is on `main`). Work there; open one PR to `main` at the end.
- **Rules:** `CLAUDE.md` ("always take the shortest way"; never skip a test; never weaken a check on stock, money or
  patients' data). The two-colour theme rule stands (`src/themes.js duoVars`, `src/styles/duotone.css`): new UI uses the
  theme's shades; the only real red is `--block` / `Tones.block`, for what blocks a sale or deletes data.
- **Each item = both apps.** React first, then Flutter (`rxpos_flutter/PARITY.md`: add a row per item).
- **Tests while working:** `npm test -- <suite>` (one or a few suites), `npx eslint src`, and in `rxpos_flutter/`:
  `flutter analyze` and `flutter test test/widgets/app_flow_test.dart --plain-name "<name>"`. Add a check for every item
  (React: the nearest suite in `tests/`, a new suite goes in `tests/run-all.mjs` and `tests/suite-times.json`;
  Flutter: `test/widgets/app_flow_test.dart`). The full suites run in CI.
- **Screenshots for the owner:** `SHOTS_PC=1 SHOTS_THEME=mint-teal SHOTS='/,/pos,/sales' npm test -- shots-all`
  (files land in `tests/.output/all/`); Flutter: `flutter test test/widgets/app_flow_test.dart --dart-define=SCREENS=true
  '--dart-define=LOOK={"v":4,"theme":"mint-teal","surface":"flat"}' --update-goldens --plain-name "screens of every page, fit-pc"`
  (files in `test/widgets/screens/`, not committed).
- **Commit** after each batch (or sooner), with the item names; tick the boxes below in the same commit.
- **Release (only when every box is ticked):** bump `package.json` to 1.13.0 (`npm version 1.13.0 --no-git-tag-version`),
  add the 1.13.0 section to `docs/RELEASE-NOTES.md` and the parity rows; push; PR to `main`; CI green; squash-merge
  (Flutter publishes by itself, `flutter-apps.yml`); then Actions → **Build RxPOS** → Run workflow on `main` with
  *release* `v1.13.0` and *deploy* `with release`; watch both runs to the end and report.
